# ChurchOS H5 实施计划

> **English version:** [2026-07-15-churchos-h5.md](./2026-07-15-churchos-h5.md)

> **供智能开发执行者使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，逐项执行本计划。所有步骤使用复选框（`- [ ]`）跟踪进度。

**目标：** 构建完整、响应式的 ChurchOS 需求共创 H5 与桌面网站，使登录注册、需求提交、点赞评论、分享、通知、活动设置和管理员后台形成可实际操作的演示闭环。

**架构：** 保留现有 Node.js、Express 和 JSON 文件持久化方案，将服务器重构为可测试的应用工厂，并把单体前端脚本拆分为职责清晰的原生 ES 模块。浏览器端使用单一应用外壳管理页面与弹窗状态，所有写操作通过 REST API；AI、邮件、定位和翻译使用确定性演示适配器。

**技术栈：** Node.js 18+、Express 4、Multer、QRCode、Lucide、HTML5、CSS3、原生 ES Modules、Node Test Runner、Supertest。

## 全局约束

- 严格遵循 `docs/superpowers/specs/2026-07-15-churchos-h5-design.md` 已确认的范围。
- 前端保持无框架，不迁移到 React、Vue 或构建工具。
- 本地数据继续保存在 `db/` 下的 JSON 文件中。
- 不接入真实 AI、邮件、短信、OAuth、支付或生产数据库。
- 必须验证 375x812、390x844、430x932、768x1024 和 1440x900 视口。
- 操作类图标使用 Lucide；仅 ChurchOS 十字标识作为自定义品牌图形保留。
- 卡片圆角不超过 8px，弹窗外壳可使用 12px。
- 移动端可交互控件高度至少 44px。
- 不提交 `node_modules/`、用户上传文件、生成的导出文件或浏览器截图。

## 文件结构与职责

- `server.js`：只负责读取端口并启动服务。
- `app.js`：Express 应用工厂、中间件、静态资源和路由挂载。
- `db.js`：支持自定义数据库目录的 JSON 数据适配器。
- `routes/auth.js`：登录、注册和教会名称联想。
- `routes/wishes.js`：需求、点赞、评论、翻译和拆分申诉。
- `routes/admin.js`：分析、合并、申诉审批、活动设置、导出和模拟邮件进度。
- `routes/share.js`：公开活动状态和二维码生成。
- `lib/http.js`：身份验证中间件和统一 HTTP 错误处理。
- `lib/serializers.js`：用户与需求的公开响应结构。
- `public/index.html`：语义化应用外壳和弹窗结构。
- `public/styles/tokens.css`：颜色、间距、字体、阴影和尺寸变量。
- `public/styles/base.css`：重置、页面外壳、可访问性和公共基础样式。
- `public/styles/components.css`：按钮、表单、卡片、弹窗、Toast、标签、头像和底部抽屉。
- `public/styles/pages.css`：首页、需求广场、详情、分享和后台布局。
- `public/styles/responsive.css`：手机、平板和桌面响应式规则。
- `public/js/api-client.mjs`：请求、身份注入、文件下载和错误归一化。
- `public/js/store.mjs`：全局状态与订阅。
- `public/js/ui.mjs`：弹窗、Toast、加载、焦点和图标辅助函数。
- `public/js/i18n.mjs`：界面文案和当前语言。
- `public/js/auth.mjs`：登录注册、会话恢复和教会联想。
- `public/js/landing.mjs`：倒计时和底部快捷抽屉。
- `public/js/wishes.mjs`：列表、筛选、排序、点赞、提交和详情。
- `public/js/comments.mjs`：评论、二级回复和翻译切换。
- `public/js/sharing.mjs`：分享弹窗、二维码、Canvas 海报、复制和下载。
- `public/js/notifications.mjs`：未读数量和通知面板。
- `public/js/admin.mjs`：后台标签页、分析、设置、申诉、导出和邮件进度。
- `public/js/app.mjs`：应用组合、页面切换和模块协调。
- `test/`：隔离数据库、API 和前端模块测试。
