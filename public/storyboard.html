早期共创计划 · 注册登录 UI 视觉跳转流程图 (交互演示板)

💡 前端 UI 还原度与流程走查说明

本页面汇集了在 9:16 移动端 H5 视口下生成的高保真 UI 还原图。通过下方的时间轴序列，您可以完整走查从游客进入、被拦截、跳转注册，到注册成功后重定向返回登录，再到登录成功和一键分享的完整界面过渡细节。点击任意图片可进行全屏放大查看。

1

第一阶段：H5 专属首页面（游客只读版） VISITOR LANDING

游客扫码或打开分享链接直接进入的首页面。界面采用深灰板岩底色，完全展示产品的愿景介绍及事工矩阵详情。

  • 防错设计：中间的“排班冲突、财务大考、关怀漏网”板块采用纯文字垂直平铺，没有任何卡片外框或大图标，防止用户产生“这里可以点击”的误判。
  • 快捷入口：底部堆叠四大行动点。首按钮“1. 注册/登录”以亮白色实心聚焦；其余为灰色线框按钮。
  • 地球仪 AI 选择器：顶部右上角设有 🌐 翻译下拉菜单。
▼ 点击 "1. 注册 / 登录" 或 触发拦截操作（点击提需求/点赞/评论）
2

第二阶段：系统拉起登录弹窗 (同工登录) LOGIN TAB ACTIVE

页面背景自动高斯模糊（Blur 10px），从屏幕正中淡入毛玻璃拟态登录窗口。默认激活 Tab A “同工登录”。

  • 极简输入：仅要求输入同工电子邮箱与登录密码，按钮亮白突出。
  • 引导注册链接：输入框最下方展示 `没有账号? 立即加入共创 (注册) ▶` 的文字链接。
▼ 没有账号？点击底部链接跳转注册
3

第三阶段：切换至注册窗口 (加入共创) REGISTER TAB ACTIVE

同工点击注册链接，弹窗面板无缝切换为 Tab B “加入共创 (注册)”，高度适配同工画像搜集。

  • 真实姓名提示：展示姓名输入框下方提示 “建议使用真实姓名，未来可能会进入致谢墙”。
  • IP 静默地理预填：所在地区自动识别网络 IP 填入，同工可以直接手动清空并重写，完成纠偏。
  • 教会联想与职务：所属教会输入可自动搜索，所在职务提供包括“财务/出纳”在内的 13 种职务点选。
▼ 填写无误点击提交注册 ── 注册成功！
4

第四阶段：注册成功 ── 自动重定向回登录面板 SUCCESS REDIRECT

同工点击提交后注册成功，系统弹出绿色 Toast 成功通知，且绝不执行静默自动登录。

  • 自动视图切换：弹窗内的 Tab 面板在一秒内滑移切回 Tab A “同工登录” 页面。
  • 邮箱自动预填：系统自动提取刚刚注册成功的邮箱地址并填入“同工电子邮箱”框中。同工只需聚焦密码框输入密码，即可快速登录，安全无漏。
▼ 登录成功，重回首页（右上角头像亮起，底部浮条隐去） ── 点击 "4. 我要分享"
5

第五阶段：我要分享（链接已复制 + 二维码海报长按保存） OPTION C SHARING OVERLAY

登录成功的同工在首页或广场点击“我要分享”后弹出的双重分享渠道。

  • 链接静默复制：系统自动复制当前共创推广短链，顶部弹出青色提示条 `链接已成功复制，可直接粘贴分享！`。
  • 磨砂海报遮罩：正中浮现一张 2:3 纵向海报。同工可以在浏览器或微信中直接长按这张海报保存到相册，或直接转发到服侍同工群中，极度利于社交圈裂变。
